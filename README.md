# PVC Price Forecasting

Прогноз SG-5 (Китай), DAP Достык на 13 недель. Отсечка **2026-07-03**. Результат — индекс k в исходном обезличенном масштабе. Модель Q68_Basket_Quantile: историческая sMAPE **6.859%**, naive **7.603%**, 225 общих полных окон. На h1/h4/h13: 2.292/4.921/10.495%. Скрытый holdout неизвестен; цель 3.5% не достигнута.

## Быстрый запуск

Проверено на Python 3.14.3. Закрытый исходный XLSB получают отдельно у организаторов; положите его как `data/pvc_raw.xlsb`. В Git он отсутствует. Данные публичных источников заморожены в `submission/public_inputs`, запуск не обращается в сеть.

Одна команда (установка зависимостей требует сети):

```sh
./run_submission.sh /absolute/path/to/pvc_raw.xlsb
```

Или по шагам:

```sh
python3.14 -m venv .venv
.venv/bin/python -m pip install -r submission/requirements-final.lock
PYTHONPATH=src .venv/bin/python -m pvc_intelligence.final_pipeline run --raw data/pvc_raw.xlsb
```

Последняя команда воспроизводит подготовку из raw, обучение и оба CSV. Отдельно:

```sh
PYTHONPATH=src .venv/bin/python -m pvc_intelligence.final_pipeline train --raw data/pvc_raw.xlsb
PYTHONPATH=src .venv/bin/python -m pvc_intelligence.final_pipeline predict --raw data/pvc_raw.xlsb
PYTHONPATH=src .venv/bin/python submission/tools/validate_submission.py
```

`train` сохраняет `build/final/model.cbm`, журнал и приватные промежуточные таблицы; `predict` загружает модель, пересобирает признаки и выводит прогноз. `run` делает оба шага. Новая отсечка/другой target требуют новой проверки: механизм fail-closed отклоняет отсутствующий target или неактивные источники. Метрики этой сдачи относятся только к зафиксированным target/отсечке.

## Метод и ограничения

80 признаков: собственная динамика SG-5, китайский спот, базис/кривая фьючерсов DCE, официальная цена NBS, два ряда Brent из исходного файла, две акции производителей и два широких индекса Китая. Это совместная модель всех источников, с абляциями содержания и задержки. Будущие значения внешних рядов не используются. Все обучающие исходы строго раньше отсечки, target не заполняется. Полная матрица из raw и 13 прогнозов совпадают с сохранённой исследовательской моделью в пределах 1e−12.

Некоторые публичные архивы получены позднее исторической даты: точные первые версии публикаций не сертифицированы. История использовалась многократно для поиска; это исследовательские оценки, не независимый holdout. Квантильные узлы не являются откалиброванными интервалами. Политические шоки и закрытия маршрутов нельзя гарантированно предсказать.

Письменное DEMO требует отдельного разрешения внешних данных; пользователь сообщил о таком разрешении на встрече. Отдельное письменное подтверждение отсутствует. Итоговые баллы организаторов и закрытый P&L неизвестны.

## Приватность и исследовательская история

Все исходные исследования сохранены локально. Публикуемый репозиторий собирается по белому списку: код, публичные числовые снимки, итоговый прогноз и агрегированные метрики. Закрытый XLSB, исторические факты/метки и производные признаки, секреты, окружение и обученные модели туда не входят. Для научного аудита закрытых предсказаний нужен локальный доступ к исходной рабочей папке.
