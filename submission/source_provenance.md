# Источники и границы использования

| Вход | Происхождение | Доступность / смысл |
|---|---|---|
| Закрытый `data/pvc_raw.xlsb` | Организаторы, предоставленный файл | Только факт / обучающая выборка / дата ≤03.07.2026. Target DAP включает доставку. Индекс k анонимизирован; денежная база неизвестна. |
| `spot.csv` | Публичные датированные таблицы SunSirs, URL в каждой строке | Следующий календарный день, срок годности 21 день. Китайский внутренний PVC-спот и расчётные базисы; не точная экспортная поставка DAP. Первые версии публикаций не сертифицированы. |
| `contracts.csv` | Истории отдельных контрактов DCE, получены через публичный Sina | Только котировки до предыдущего дня, одновременные near/far, срок давности 7 дней. Контракты не склеиваются в ценовой уровень непрерывного фьючерса. |
| `nbs.csv` | NBS КНР, официальные датированные публикации, URL в каждой строке | Дата доступности в источниковом реестре; SG-5 внутри КНР. Архивные ревизии независимо не восстановлены. |
| `zhongtai.csv`, `tianye.csv` | Публичные Sina, проверка пересечений Tencent; локальный аудит `results/producer_equity_v67/adjustments_001` | Индексы роста с учётом доступных ex-reference/датированных HFQ-факторов; не гарантированная полная total-return история. Источник 2016-09-09 Tianye с несовпадением поставщиков исключён. |
| `shanghai.csv`, `shenzhen.csv` | Публичные широкие индексы Sina, контроль общего фондового рынка | Следующий день, давность 14 дней; нельзя интерпретировать их как физический спрос на SG-5. |

Публичные числовые снимки заморожены для автономного повторного запуска. SHA-256 и исходные локальные пути: `public_inputs/manifest.json`. Они не содержат закрытого целевого ряда и закрытых Brent-значений. Признаки исходных Brent пересобираются только из XLSB пользователя. Собственный дневной рост не заменяет котировку этилена, карбида или тарифа China→Dostyk.

Права доступа: по записи встречи пользователь сообщил, что внешние данные разрешены. В письменном DEMO отдельное разрешение требуется, а отдельного письма нет среди предоставленных документов; его следует приложить перед конкурсной отправкой. Автоматическая отправка организаторам не выполнялась.

Первая публикация ряда архивов не подтверждена независимо. Поэтому корректно говорить о прошлых датах и проверках задержек, но не о доказанном доступе к каждой точной архивной версии в реальном времени. Этот риск не снимается дополнительной неделей задержки.

Перечень исследований и исходные архивы сохранены локально. В публикуемом пакете нет закрытого XLSB, исторического target, меток, матриц признаков, таблиц исходных предсказаний с actual и моделей, из которых можно извлекать закрытые данные.
